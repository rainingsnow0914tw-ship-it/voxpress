# VoxPress v0.2 readiness

VoxPress v0.2 is being prepared as a privacy-conscious, maintainable open-source release. This document records the release gates without claiming that an unpublished version is already available.

## Completed in the release branch

- Refactored the Windows hotkey, audio, transcription, paste, configuration, logging, tray, and lifecycle boundaries.
- Added synthetic tests that do not register a global hook, open a microphone, use a real clipboard, or download a model.
- Removed transcript text from console and tray output.
- Added bounded temporary-audio cleanup, metadata-only logs, a single-instance guard, and safer paste/focus handling.
- Added blocking lint, test, and package jobs for CI.
- Added contributor, security, privacy, architecture, changelog, and release documentation.
- Passed 166 synthetic non-live tests locally on 2026-08-12, including a native Win64 `INPUT` ABI-size guard and regressions for hotkey pairing, cancellation, focused-window injection, model-label redaction, shutdown, and exact payload preservation under the optional voice marker.
- Built candidate wheel/source distributions, installed the wheel in an isolated environment, and scanned both candidate artifacts for private markers and user-data filenames with no findings.

## Required before publishing v0.2

- Pass the full GitHub Actions matrix on the public branch.
- Build the Windows executable from the tagged commit and publish its SHA-256 checksum.
- Verify a source install and the packaged executable on a clean Windows account or machine.
- Perform explicit live acceptance for the global hotkey, microphone, focus changes, clipboard retention/recovery, typing mode, and shutdown.
- Confirm that release artifacts and documentation contain no personal vocabulary, transcripts, logs, audio, credentials, machine paths, or private assistant behavior.
- Obtain maintainer approval before merging, tagging, pushing artifacts, or changing the live installation.

## Claim boundary

Until those gates pass, describe v0.2 as an in-progress release branch. Do not claim that it is published, available on PyPI, broadly adopted, or verified on every supported Windows and Python version.
